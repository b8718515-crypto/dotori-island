# 도토리섬 — 대한민국 편

동물의 숲풍 브라우저 게임. `dotori-island.html` 파일 하나로 동작한다.

- 실행: `dotori-island.html`을 브라우저로 열기
- 지도: 한반도 전체(남·북) 2928×4624칸, 1칸 ≈ 0.24km. 실제 시·도 경계, 실제 고도(AWS Terrain Tiles)로 정한 산·고원·눈밭, 고도에서 물 흐름으로 찾은 강(한강·낙동강·금강·대동강·압록강·두만강 등). 넓어서 16×16칸 구역마다 가까이 갈 때 만든다
- 북쪽: 평양·함흥·청진·원산·신의주·개성 등 도시, 서북·동북 사투리, 백두산 천지·대동문·묘향산·금강산 등 명소, 국경 너머(중국·러시아)는 갈 수 없는 땅
- 지형: 태백·소백·차령·노령·광주산맥, 한라산·지리산·설악산, 한강·낙동강·금강·영산강·섬진강, 호남평야의 논, 서해안 갯벌, 휴전선 너머(갈 수 없음)
- 도시 29곳: 광역시는 아파트 단지, 주민은 고장 사투리(서울·강원·충청·전라·경상·제주)로 말함
- 명소: N서울타워, 광화문, 수원 화성, 첨성대, 하회마을, 전주·북촌 한옥마을, 돌하르방, 한라산 백록담, 성산일출봉, 보성 녹차밭, 해운대, 등대, 독도
- 여객선: 목포↔제주, 포항↔울릉도↔독도, 인천↔백령도 (뱃삯 도토리 300개)
- 주민: 보리(곰)·솜이(토끼)·모카(고양이), 외계인 3인조 꺼멍이·하양이·노랑이, 그리고 각 고장 주민
- 문명식 발전 (V 또는 마을 게시판):
  - 내 마을 키우기: 목재(나무 흔들기)·돌·점토·철광석(바위)·도토리로 내 집 → 상점 확장 → 공방 → 항구 → 학교를 지으면 마을 레벨(움막~배움 시대)과 영토 반경이 커지고, 지도에 영토 경계가 칠해진다
  - 기술: 농업(재생 2배) → 건축(새 마을·건물 20% 할인) → 항해(항구·나무배)
  - 새 마을: 영토 밖 빈 풀밭에 마을 회관을 세우면 가까운 내 마을까지 흙길(A* 경로)이 닦인다. 길 위에선 더 빨리 걷는다
  - 교류: 도시 주민 부탁 +3, 첫인사 +1, 선물 +2 → 우호도 10이면 동맹, 5분마다 고장 특산물이 마을 창고로 온다
  - 나무배: 맨손으로 물가를 보고 Space → 바다·강을 자유롭게 오가며 울릉도·제주·백령도까지
- 전쟁 (V › 전쟁): 가상의 동물 왕국 5곳(🦊 여우 제국·🐺 늑대 부족·🦝 너구리 왕국·🐗 멧돼지 연합·🦦 수달 해적단)이 요새 10곳을 차지하고 있다
  - 군사 기술 → 병영 → 병사 모집(5명씩, 정원은 마을 레벨·마을·점령 요새에 따라 증가)
  - 적 요새로 진군 → 병력 대 수비대 자동 전투 → 수비대가 무너지면 성문 앞 장수와 야차룰 대장전 → 이기면 요새 점령, 수도를 빼앗으면 왕국 항복
  - 전투 판정(문명 5식): 힘의 비율을 비선형으로 키워 여러 합을 겨루고, 먼저 절반 아래로 무너진 쪽이 진다. 힘이 비슷하면 운에 달리고 양쪽 다 크게 다치며, 압도하면 적게 잃는다. 전쟁 창에 승산·예상 손실, 침공 경보에 막을 확률이 나온다
  - 행군은 지형을 따라간다(16×16칸 구역 A*): 높은 땅·강은 느리고, 흙길은 빠르고, 바다는 배로 느리게, 국경 너머는 못 간다. 지도에 남은 길이 점선으로 보인다
  - 군사를 배우면 왕국들도 7~12분마다 내 마을·요새로 쳐들어온다 (화면 위 침공 경보). 마을 수비 병력이 막고, 지면 약탈당하거나 요새를 빼앗긴다
- 진영: 처음 시작할 때 🌸 남부 연합(충남 공주 도토리 마을) 또는 ❄️ 북부 연합(평안남도 솔방울 마을)을 고른다. 마을 발전(V) › 진영에서 남북 영토 점수와 봇 현황·소식을 본다
- AI 봇: 사람 대신 움직이는 컴퓨터 지도자들. 양쪽 진영에서 수도를 세워 레벨을 올리고, 새 마을과 길을 내고, 병사를 모아 동물 왕국 요새·상대 진영 마을·플레이어를 친다 (플레이어는 군사를 배우거나 Lv.3이 된 뒤부터). 성향은 평화·균형·공격·배신자(같은 편 뒤통수). 봇 지도자에게 말을 걸어 선물·휴전(15분)·공물·화해·선전포고·야차룰. 봇 마을을 빼앗을 수 있고 수도를 무너뜨리면 그 봇은 망한다
  - 대전략: 봇마다 내정·정복·교역·복수 가운데 목표를 점수로 고른다(성향 + 형편 + 운 + 유지 보너스, 같은 편이 몰린 목표는 감점, 한 번 고르면 5분 유지). 교역 중인 같은 편은 사이가 좋으면 교역품을 보낸다
  - 기억과 평판: 봇은 선물·선전포고·휴전 위반·같은 편 공격·정복을 기억하고 소문을 낸다. 평판이 휴전 가격(원한이 깊으면 거절), 배신 확률, 공격 대상, 대사를 바꾸고 시간이 지나면 옅어진다. 요새·마을을 빼앗을수록 전쟁광 평판이 올라 모든 봇이 경계한다. 휴전 중인 적은 "휴전 깨고 진군"으로 칠 수 있다
- 설정 › AI 봇: 켜기/끄기, 진영마다 봇 수(0~6), 성향, 난이도, 속도, 봇 새로 만들기
- 조작: WASD 이동, Space 행동, M 지도, V 마을 발전, I 가방, C 도감 / 야차룰 맞짱: Space 주먹, F 막기, Shift 구르기, E 던지기
- 개발: 밸런스 숫자는 코드의 `BAL` 표 한곳에 있다. 전투·봇·침공의 난수는 시드가 있는 `GR`(세이브에 상태 저장)을 쓴다. 한 틱은 세계(요새·행군·침공) → 세력(봇·동맹) → 화면 순서. 주소에 `?debug`를 붙이면 콘솔에서 `window.DOTORI`로 상태와 규칙 함수를 볼 수 있다
